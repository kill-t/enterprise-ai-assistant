# Enterprise AI Assistant

面向 AI 应用后端岗位的企业办公智能助手项目。

项目将逐步实现多轮会话、可追溯知识检索、基于 MCP 的办公工具调用、受控
多 Agent 工作流、人工审批和可观测的任务执行。

## 仓库结构

- `backend/`：FastAPI 应用、数据库迁移和后端测试。
- `frontend/`：Vue 3 演示界面。
- `infra/`：本地基础设施与部署配置。
- `docs/`：架构决策、项目上下文和学习笔记。
- `scripts/`：开发与演示辅助脚本。

项目正在迭代中。每完成一个可运行的功能切片，都会补充对应的启动、验证和
演示说明。
