# 1. Project Overview

## Project Name

Enterprise AI Assistant

## Goal

Build an enterprise-level AI Assistant backend for learning modern AI application development.

The project is NOT a simple chatbot.

The target architecture includes:

- Enterprise Conversation System
- LLM Gateway
- Prompt Management
- Short-term Memory
- Long-term Memory
- Context Management
- Tool Calling
- Agent
- RAG
- Streaming Response

The final goal is to become an Agent Platform rather than a chat demo.

# 5. LLM Layer

Provider abstraction has been completed.

Structure:

```
BaseChatProvider

        │

        ├── MockProvider

        └── DeepSeekProvider
```

ProviderFactory selects provider.

Future providers should only implement BaseChatProvider.

ConversationService should never depend on provider implementation.

# 15. Design Principles

This project follows Clean Architecture principles.

Rules

- Service never writes SQL.
- Repository never calls LLM.
- PromptBuilder never queries DB.
- Provider never knows business logic.
- MemoryManager hides storage implementation.
- Router only handles HTTP.

Each module should have a single responsibility.
