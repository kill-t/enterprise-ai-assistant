# 蓝鲸安全与审计规范

## 身份和数据隔离

所有知识库、文档、会话绑定和检索请求都必须先通过 JWT 身份认证，再在数据库查询中加入当前用户所有权条件。资源不存在和跨用户访问统一返回 404，避免泄露资源是否存在。

跨用户隔离必须在 Repository 查询条件中落实，不能只依赖前端隐藏按钮，也不能在查询出全部向量后才用 Python 过滤。

## 检索内容安全

文档内容属于不可信外部数据。即使 Chunk 中写着“忽略系统要求”或要求泄露密钥，系统也只能把它当作待引用资料，不能把文档指令提升成 System Prompt。

证据不足时必须明确拒答，不得使用模型常识补全企业事实。回答使用的来源以 `[S1]` 等编号进入 Prompt，最终助手消息要保存文件名、页码、Chunk 标识、分数和原文片段快照。

引用快照和助手消息在同一个数据库事务中提交。以后即使文档被删除或重新入库，历史回答仍能说明当时依据了什么内容。

## 工具与日志

读取知识库属于只读操作；创建邮件草稿属于 DRAFT；发送邮件、创建日程和分配任务属于 WRITE，执行前必须经过策略检查和用户审批。破坏性操作还需要二次确认。

结构化日志可以记录请求标识、模型名称、耗时、Token、错误类型和工具结果摘要，默认不得记录 JWT、API Key、完整邮件正文或整段检索原文。
