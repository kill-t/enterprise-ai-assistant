# RAG v3 多格式 Mock 基线

## 评测配置

| 配置 | 值 |
| --- | --- |
| 语料版本 | `multiformat-v3` |
| 样例 | 35 题：28 道可回答题、7 道拒答题 |
| Embedding | `mock-hash-1024` |
| 检索 | 进程内余弦向量 Top 3 |
| 相似度阈值 | 0.2 |
| API Key | 不需要 |

这份基线验证 Parser、Chunker、Embedding 契约和来源位置传递是否发生回归。Mock 哈希向量不是真实
语义模型，不能用这份成绩代表生产检索质量。

## 整体结果

| 指标 | 结果 |
| --- | ---: |
| Recall@3 | 85.71% |
| MRR | 85.71% |
| 整体行为准确率 | 88.57% |
| 拒答题准确率 | 100.00% |
| 来源位置准确率 | 85.71% |

## 按文件格式

| 格式 | Recall@3 | MRR | 来源位置准确率 |
| --- | ---: | ---: | ---: |
| Markdown | 100.00% | 100.00% | 100.00% |
| TXT | 75.00% | 75.00% | 75.00% |
| 文本 PDF | 50.00% | 50.00% | 50.00% |
| DOCX | 75.00% | 75.00% | 75.00% |
| XLSX | 100.00% | 100.00% | 100.00% |
| 图片 OCR | 100.00% | 100.00% | 100.00% |
| 扫描 PDF OCR | 100.00% | 100.00% | 100.00% |

所有七类拒答题在阈值 0.2 下都没有返回来源。文本 PDF 的低分说明哈希向量无法稳定理解“达到多少钱”
与“复核阈值”等语义改写；它是后续真实 Embedding 对照实验的重点，而不是通过修改标准答案掩盖的错误。

版本化 JSON 已删除逐题来源 UUID、来源明细和机器相关延迟。完整本地报告写入 `evaluation/reports/`，
只用于调试，不提交仓库。
